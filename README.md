# 数字人智能体私有交付备份

数字人智能体是一套面向短视频 IP 运营、门店获客、品牌口播和内容团队的数字人口播生产工具。它把参考视频学习、文案改写、声音克隆、数字人生成、画中画混剪、封面制作、配乐导出和平台发布交接放在同一个桌面工作台里，目标是让非技术用户也能完成从素材到成片的完整流程。

本仓库是私有 GitHub 仓库中的脱敏交付备份版本，用于版本留存、协作排查和后续升级，不是公开发行源码仓库。

## 产品定位

数字人智能体主要解决三个问题：

1. 把客户提供的参考内容、产品信息或本地素材快速整理成可拍、可读、可发布的口播脚本。
2. 用云端数字人、声音克隆和本地剪辑能力生成可交付的短视频成片。
3. 通过授权、积分和运营后台控制客户使用额度，便于商业化售卖和持续更新。

适用场景包括本地生活门店口播、招商加盟视频、产品种草短视频、企业老板 IP、知识分享口播、批量素材混剪和客户试用交付。

## 核心功能与技术原理

### 1. IP 深度学习与参考视频解析

用户可以输入参考视频链接、产品资料或现有文案，系统会提取其中的主题、标题、标签、关键词和可复用表达，并同步到后续脚本区。

技术原理：

- 链接解析：对公开可访问的视频链接尝试本地解析和下载；受平台登录、验证码、权限或风控限制时，提示用户改用本地上传。
- 音频抽取：使用 FFmpeg 从视频中抽取音频轨道。
- 语音识别：使用 FunASR / Paraformer 等中文 ASR 能力把音频转成文字。
- 文案整理：通过大模型或本地规则对识别文本进行标题、标签、关键词和脚本结构化处理。

### 2. 文案改写、标题和标签生成

系统可以在原文案主题不变的基础上改写部分表达，生成更适合口播的脚本，同时提取发布标题、平台标签和封面关键词。

技术原理：

- LLM 适配层：通过 OpenAI-compatible / DeepSeek / 其他云端模型接口进行文本生成。
- 提示词约束：限制输出主题、字数、口播风格和平台用语，避免生成偏题内容。
- 结构化输出：把标题、标签、关键词、脚本文案拆成独立字段，供封面、发布和剪辑模块复用。

### 3. 声音克隆与语音合成

用户可以上传声音样本或选择预设声音，让系统用指定声音读取当前脚本文案，生成口播音频。

技术原理：

- 声音克隆：把用户授权的声音样本上传到云端 TTS/声音克隆服务，生成可复用的 voice id。
- 语音合成：将脚本文本、语速、情绪等参数发送到语音模型，输出 WAV/MP3 音频。
- 复用缓存：已经克隆成功的声音会记录 provider voice id，避免同一声音重复克隆。

### 4. 数字人形象与口播视频生成

用户可以上传人物视频创建数字人形象，也可以选择已创建的数字人和声音生成口播视频。

技术原理：

- 云端数字人 API：通过飞影等数字人服务提交形象、声音和脚本生成任务。
- 对象存储中转：本地视频、音频需要先上传到 OSS 等对象存储，云端模型才能访问素材。
- 任务轮询：后端保存任务状态并轮询云端结果，前端显示生成进度和最终视频。
- 付费调用确认：真实云端模型调用会消耗额度，系统在调用前要求明确确认。

### 5. 视频编辑、画中画和字幕

系统支持在数字人口播视频中插入产品图或素材视频，并自动生成字幕、调整字幕位置、字号和颜色。

技术原理：

- 本地 FFmpeg 混剪：使用 FFmpeg 对主视频、素材视频、图片、音频和字幕进行合成。
- 画中画规则：默认前 8 秒保留数字人，最后 3 秒回到数字人，中间时间由上传素材按顺序平分填充。
- 字幕烧录：用中文字体把脚本文字或 ASR 对齐结果烧录到视频画面中，避免播放器兼容问题。
- 时间轴处理：根据视频时长、素材数量和字幕分段生成滤镜参数，输出最终 MP4。

### 6. 配乐与最终导出

用户可以选择内置背景音乐，试听后把音乐混入最终成片，并下载 MP4。

技术原理：

- 音频混合：使用 FFmpeg 对口播音频和背景音乐做音量控制、裁剪和混音。
- 成片封装：统一导出 MP4，方便上传抖音、小红书、视频号等平台。
- 本地预览：生成后的文件保存在本地任务目录，前端直接预览和下载。

### 7. 封面制作

系统可以根据当前视频、标题和关键词生成封面，用户也可以选择模板并预览。

技术原理：

- 模板渲染：使用封面模板叠加标题、关键词和背景图。
- 关键词复用：封面关键词默认来自标题标签模块，减少重复填写。
- 图片导出：生成 PNG/JPG 封面文件，供发布或人工上传使用。

### 8. 平台发布辅助

系统提供抖音、小红书、视频号等平台的浏览器辅助发布入口，帮助用户打开发布页、上传成片并填写标题标签。

技术原理：

- Playwright 浏览器自动化：复用本机 Edge/Chrome 登录态打开平台创作者页面。
- 本地登录态：不保存平台密码，只保存浏览器自身的登录状态。
- 人工最终确认：系统只辅助上传和填写，最终发布动作必须由用户确认。

### 9. 授权、积分和运营后台

软件支持客户授权码、设备绑定、积分扣费、套餐管理、版本更新和客户状态管理。

技术原理：

- 服务端授权校验：客户端启动和调用高成本能力时向后台校验授权状态。
- 设备绑定：授权码可绑定限定数量设备，避免授权码无限扩散。
- 积分计费：云端数字人和声音克隆按服务用量扣积分，后台记录消费明细。
- 运营后台：管理员可新增客户、生成授权、停用授权、重置设备、查看订单和维护版本。

## 技术架构

- 桌面外壳：Electron + Chromium，用于 Windows 桌面应用和本地窗口体验。
- 前端界面：原生 HTML / CSS / JavaScript，保持轻量、易打包、易同步。
- 后端服务：Python + FastAPI + Pydantic，提供模型配置、任务调度、文件处理和授权接口。
- 打包方式：后端通过 PyInstaller 冻结为可执行文件，前端和后端随 Electron 一起交付。
- 媒体处理：FFmpeg 负责音频抽取、视频转码、字幕烧录、画中画和混音。
- 语音识别：FunASR / Paraformer 用于中文视频转写。
- 云模型接入：通过适配器模式接入飞影、阿里云 DashScope、对象存储、LLM 网关等服务。
- 浏览器自动化：Playwright 用于发布辅助和平台登录态复用。
- 商业化后台：授权码、设备绑定、积分扣费和订单发货由服务端统一控制。
- 大文件管理：GitHub 仓库使用 Git LFS 存储 exe、dll、asar、pak 等大文件。

## 本仓库已做的脱敏处理

本仓库用于私有备份，上传前已经处理：

- 已移除运行缓存、客户素材、发布记录、浏览器登录态和诊断产物。
- 已清空云服务 API Key、Token、Secret 和临时签名下载链接。
- 已删除项目运行产物和客户上传素材，避免泄露客户数据。
- 已保留必要的程序文件、运行组件、空配置模板和产品代码。

## 本地运行前需要重新配置

由于本仓库不保存真实密钥，运行前需要在软件设置页重新配置：

- 飞影数字人 API
- 阿里云 DashScope / CosyVoice
- 阿里云 OSS 或其他对象存储
- LLM 文案模型接口
- 授权后台地址和客户授权信息

不要把真实 API Key、客户素材、登录态、模型权重或生成产物提交到仓库。

## Git LFS 使用说明

首次克隆后需要执行：

~~~powershell
git lfs install
git lfs pull
~~~

否则 exe、dll、asar、pak 等大文件只会显示为 LFS 指针文件，软件无法完整运行。
