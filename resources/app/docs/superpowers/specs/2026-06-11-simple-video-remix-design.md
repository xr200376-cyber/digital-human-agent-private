# 最简视频混剪页面设计

## 背景

当前 `数字人制作` 和 `视频生产` 都包含脚本、创建任务、生成视频相关功能，用户会分不清入口。新的产品边界是：`数字人制作` 继续保留一体化数字人口播制作；`视频生产` 改为 `视频混剪`，只做已生成视频的发布版加工。

## 目标

把左侧 `视频生产` 改成 `视频混剪`，页面只保留主流程必须的功能：

1. 选择主视频。
2. 上传混剪素材。
3. 选择生成数量。
4. 一键生成混剪视频。

## 非目标

本次不在 `视频混剪` 页面保留以下功能：

- 视频主题输入。
- 脚本生成。
- 脚本审核。
- 渲染档位。
- 视频模板 JSON 预览。
- 高级任务参数。

这些能力继续留在数字人制作、任务队列或后续高级设置里，不作为混剪页主流程。

## 页面结构

页面标题：`视频混剪`

主区域采用单页表单：

```text
主视频
[选择已生成数字人视频] [上传本地视频]

混剪素材
[上传图片/视频素材]

生成数量
[生成 1 条] [生成 3 条] [生成 5 条]

[一键生成混剪视频]
```

## 默认规则

为了保持简单，后台使用默认规则：

- 比例：竖屏 9:16。
- 字幕：优先沿用主视频字幕；没有字幕时后续再接语音识别。
- 配乐：默认轻音乐占位。
- 片头片尾：默认开启。
- 质量：使用稳定默认档位。
- 输出：默认 MP4。

## 数据流

1. 用户选择主视频或上传主视频。
2. 用户上传混剪素材，可以是图片或视频。
3. 用户选择生成数量。
4. 点击 `一键生成混剪视频`。
5. 系统创建混剪任务，并进入任务队列/任务详情查看结果。

## 错误处理

- 没有主视频时提示：`请先选择或上传主视频。`
- 没有素材时提示：`请先上传至少一个混剪素材。`
- 生成中按钮置灰，避免重复点击。
- 任务创建失败时展示后端返回的简短错误信息。

## 验收标准

- 左侧菜单显示 `视频混剪`，不再显示 `视频生产`。
- 混剪页不再出现脚本、主题、审核、模板 JSON、渲染档位。
- 页面能选择/上传主视频、上传素材、选择 1/3/5 条生成数量。
- 点击一键生成时能创建一个混剪任务或给出明确的未接入提示。
- 数字人制作页面原有一体化流程不被移除。
